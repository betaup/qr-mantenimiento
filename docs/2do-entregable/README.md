# Entregable 2

En esta carpeta está la evidencia de las semanas 3, 4 y 5 del proyecto, organizada por cada criterio de la rúbrica.

Organizamos la evidencia en una carpeta por criterio, con el mismo número y nombre que tiene en la rúbrica, para que sea fácil encontrar lo que se pide en cada punto. Cada carpeta tiene su propio README con lo que hicimos, lo que encontramos y las capturas que lo respaldan.

## Contenido

- **img**: todas las imágenes de la evidencia. El número al inicio de cada nombre indica a qué criterio pertenece.
- **evidencias**: una carpeta por criterio, con los resultados completos de cada herramienta y de cada prueba.
