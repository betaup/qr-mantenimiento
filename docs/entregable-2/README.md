# Entregable 2

Documento técnico de las semanas 3, 4 y 5 y la evidencia de cada criterio de la rúbrica.

- `entregable-2.tex`: el documento técnico. Las imágenes que usa están en `img/`.
- `img/`: todas las figuras del documento. El prefijo indica el criterio al que pertenecen.
- `evidencias/`: una carpeta por criterio de la rúbrica, con las salidas completas de cada herramienta y prueba.

Para compilarlo en Overleaf basta con subir `entregable-2.tex` junto con la carpeta `img/`.
